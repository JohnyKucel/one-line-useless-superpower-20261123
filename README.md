A one-line useless superpower: mind-reading that only works on the reader's own mind — and even that one mostly just buffers.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/useless-output python3 main.py
```

Writes one 73-character line to `entry.txt` in the output directory (or `output/` when `MAKEFUN_OUTPUT_DIR` is unset). Python 3.13, standard library only, deterministic — no network, no randomness, no clock.
